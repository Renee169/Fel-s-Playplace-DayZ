# Fel-s-Playplace-DayZ

Example DayZ Expansion Quests that I made for my server. Feel free to use.

There is a timed delivery chain quest to send players speeding around the map, hunting quests, kill quests, crafting quest, collection quests, etc.

Please note: The files are out of date and need to be updated to the newest version of Expansion Quest files. The Quests were made for ChernarusPlus map with custom buildings and mods so you need to adjust all positions, names, text to suit your server.

Enjoy!
